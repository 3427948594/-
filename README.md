## 项目简介

**昏晓生态**是一个完全本地运行的数字私人空间，融合了2D小屋、3D世界、本地AI模型和净土法门修行。它不是一个网页应用，而是一个可以安装到电脑上、离线运行的独立环境。

### 设计理念

- **完全本地**：所有数据存储在本地，不上传云端
- **有温度**：卡皮巴拉、光球（择西里）等角色陪伴用户
- **可修行**：集成功课计数器、经典阅读、回向等修行功能
- **可建造**：用户可以自定义场景、添加模型、扩展功能

## 快速开始

### 环境要求

- Windows 10/11
- Python 3.8+
- Ollama（可选，用于本地AI）
- 至少 2GB 可用磁盘空间

### 安装运行

#### 方式一：使用安装包（推荐）

1. 下载 `昏晓生态安装包.exe`
2. 双击运行安装程序
3. 选择安装目录
4. 安装完成后，桌面会出现「昏晓生态」快捷方式
5. 双击启动

#### 方式二：从源码运行

```bash
# 克隆项目
git clone https://github.com/your-org/hunxiao-ecosystem.git
cd hunxiao-ecosystem

# 安装依赖
pip install -r requirements.txt

# 启动
python 昏晓启动器.py
```

#### 方式三：直接打开HTML

```bash
# 进入核心App文件目录
cd 核心App文件

# 启动本地静态服务器
python -m http.server 8765

# 浏览器打开
# http://127.0.0.1:8765/小屋内景.html
```

### 首次使用

1. 启动app后，进入2D小屋
2. 点击卡皮巴拉开始对话
3. 点击光球（择西里）了解世界观
4. 右上角🔧按钮打开系统诊断
5. 点击「← 打开门」进入3D世界

## 功能模块

### 卡皮巴拉AI编程

- 位置：2D小屋左侧
- 功能：代码生成、文件操作、命令执行
- 调用：本地模型（Ollama）或云端API（DeepSeek）
- 工具代理：5601端口，支持list_dir/read_file/run_command/write_file

### 光球（择西里）

- 位置：2D小屋右上角漂浮
- 功能：世界观介绍、禅意对话、无参照镜子
- 特点：不提供答案，只回应用户的问题
- 对话："你不需要寻找我，我就在你提出问题的地方。"

### 贤普姑娘

- 位置：3D世界，动态随机出现
- 6个随机位置：左/右/左下/右下/左上/右上
- 功能：卖花、闲聊、问心事
- 出现机制：页面加载15秒后首次出现，停留12-18秒，消失后20-40秒再次出现

### 商店

- 位置：3D世界右上角🏪按钮
- 两个背景轮流切换：黄昏商店 / 光明银行
- 9种商品（全部免费）：供花、酥油灯、念珠、经典、清茶、莲花、风铃、羽毛、星光
- 半透明毛玻璃商品框

### 功课计数器

- 三种模式：念诵（点击计数）、静坐（自动计时）、读经
- 统计：今日总计、连续天数、累计总数
- 数据存储：localStorage（`hunxiao_global_state`）

### 经典阅读

- 集成：华严经15品 + 法华经10品
- 读取：通过工具代理（5601端口）读取本地经典文件
- 目录：`archive/06_宣传与分发/`

### 回向

- 自动计算可回向功德（今日功课+冥想次数+供花）
- 点击后30颗金色粒子飞向天空
- 回向后世界亮度增加
- 文字："本心无需往生，本心从未离开。"

## 本地模型集成

### 安装Ollama

```bash
# 下载安装Ollama
# https://ollama.com/download

# 拉取模型
ollama pull qwen2.5:3b

# 验证
ollama list
curl http://127.0.0.1:11434/v1/models
```

### 工具代理

```bash
# 启动工具代理（启动器会自动启动）
python 卡皮巴拉工具代理_服务端.py

# 健康检查
curl http://127.0.0.1:5601/api/health

# 对话
curl -X POST http://127.0.0.1:5601/api/chat \
  -H "Content-Type: application/json" \
  -d '{"message": "你好"}'
```

### 端口说明

| 端口 | 服务 | 说明 |
|------|------|------|
| 8765 | 静态文件服务器 | 托管核心App文件 |
| 11434 | Ollama本地模型 | LLM对话服务 |
| 5601 | 卡皮巴拉工具代理 | 文件操作/命令执行 |
| 5600 | GitHub资源代理 | 可选，GitHub API代理 |

## 诊断与运维

### 打开诊断面板

1. 进入2D小屋
2. 点击右上角🔧按钮
3. 诊断面板自动运行首次诊断

### 诊断内容

- 📋 页面信息（URL/协议/窗口尺寸/时间）
- 🎨 UI元素（12个关键元素加载状态）
- ⚡ 功能函数（6个关键函数可用性）
- 💾 本地存储（localStorage键值列表）
- 🌍 全局状态（GlobalState前10字段）
- 🔌 服务连接（本地模型11434/工具代理5601）

### 导出功能

- 📥 导出当前诊断（JSON，敏感信息自动遮蔽）
- 📋 复制摘要（纯文本，适合粘贴到Issue）
- 📦 导出全部历史（时间序列JSON）

### 历史与回放

- 自动保存最近20次诊断
- 差异高亮（新增问题/已修复）
- 回放对比（重跑诊断+并列对比）

### 自动监控

- 可开启60秒定时检查
- 异常时诊断按钮红色脉冲闪烁
- 桌面通知（需浏览器授权）

### 详细文档

参见 [docs/diagnostics.md](docs/diagnostics.md)

## 开发指南

### 环境搭建

```bash
# 克隆项目
git clone https://github.com/your-org/hunxiao-ecosystem.git
cd hunxiao-ecosystem

# 安装Python依赖
pip install -r requirements.txt

# 安装Node.js依赖（可选，用于前端开发工具）
npm install

# 启动开发服务器
python 昏晓启动器.py
```

### 代码规范

- **HTML**：语义化标签，注释清晰
- **CSS**：BEM命名规范，模块化
- **JavaScript**：ES6+，函数式优先，避免全局污染
- **Python**：PEP 8，类型提示，docstring

### 提交规范

```
feat: 新功能
fix: 修复bug
docs: 文档更新
style: 代码格式（不影响功能）
refactor: 重构
test: 测试相关
chore: 构建/工具相关
```

### 调试技巧

1. 打开诊断面板（🔧）查看系统状态
2. 浏览器开发者工具 → Console 查看错误
3. 检查端口占用：`netstat -ano | findstr :8765`
4. 查看启动器日志：控制台输出
